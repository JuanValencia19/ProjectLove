# Lovable Reference

This directory contains the original Lovable prototype.

It is a visual and technical reference only. Agents MUST NOT modify these files.

When implementing production components, agents should:

- study the relevant reference;
- preserve approved visual characteristics;
- improve architecture and maintainability;
- follow the project's DESIGN-DIRECTION.md;
- follow COMPONENT-SPEC.md and MOTION-SYSTEM.md.

Production code belongs exclusively in `src/`.
