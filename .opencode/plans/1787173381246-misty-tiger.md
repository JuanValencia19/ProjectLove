# Plan: Skills externas para los 7 agentes del proyecto

## Objetivo

Listar y mapear las **skills externas** que cada uno de los 7 agentes del proyecto necesita, para que el usuario las importe manualmente a `.opencode/skills/`. Verificado contra los repos reales vía GitHub API (estructura confirmada, todas usan formato `SKILL.md` compatible con opencode).

## Contexto

- Ya existe la skill de proyecto `.opencode/skills/ourstory-context/SKILL.md` (contexto del producto). Las skills globales de `~/.config/opencode/skills/` (sdd-*, judgment-day, branch-pr, etc.) no requieren importación.
- Formato opencode de skill = carpeta con `SKILL.md` + frontmatter. Todas las skills listadas abajo ya vienen así → se importan **copiando la carpeta** a `.opencode/skills/<nombre>/`.
- El repo es PÚBLICO: verificar licencia antes de copiar contenido de terceros (todas las listadas son MIT/permisivas salvo indicación).

## Orden de importación (para el usuario)

1. `npx skillsadd <owner/repo>` instala a `~/.claude/skills/` (formato Claude) — NO es la ruta de opencode.
2. Para opencode: copiar manualmente la carpeta `<skill>/SKILL.md` (+ assets/references si existen) a `.opencode/skills/<nombre>/`.
3. Verificar con `opencode` que las skills aparecen (autocompletado / re-lanzar sesión).

## Gotchas

- `npx skillsadd` apunta a `~/.claude/skills/`, no a `.opencode/` → la importación es copia manual, no `skillsadd`.
- No importar: skills de remotion/heygen (video, no aplica), prisma (no se usa Prisma), shadcn (no se usa shadcn), skills de agentes no-React.
- Licencias: verificar MIT antes de copiar; `anthropics/skills` y `vercel-labs` son oficiales y permisivas.
- Las skills compartidas (web-design-guidelines, frontend-design) NO duplicar carpetas: un solo `SKILL.md` en `.opencode/skills/`, varios agentes la leen.
